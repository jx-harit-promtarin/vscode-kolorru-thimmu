# Changelog

## [0.1.0] — 2026-06-10

### Added
- Rainbow animation engine using HSL hue rotation
- Commands: Start, Stop, Toggle, Configure, Pick Preset
- Status bar item with click-to-toggle support
- 7 built-in color presets (Full Rainbow, Ocean, Sunset, Forest, Purple Haze, Fire, Rose Gold)
- Configurable: interval, hue step, saturation, lightness, hue range, target UI elements
- `startOnLaunch` option for auto-start on VS Code open
